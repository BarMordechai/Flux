# שטף: MVP להודעות קוליות (שלב א')

## אפליקציית אנדרואיד (מומלץ להתחיל כאן)

אפליקציה עצמאית: כל העיבוד על הטלפון, בלי שרת, בלי אינטרנט ובלי מודל AI. הקוד בתיקייה `android/`.

* **התקנה:** בעמוד [Releases](../../releases) של הריפו מורידים בטלפון את קובץ ה-APK האחרון ופותחים אותו. אנדרואיד יבקש לאשר "התקנה ממקור לא ידוע" עבור הדפדפן. נדרש Android 8.0 ומעלה.
* **שימוש:** מקליטים בתוך האפליקציה, או בוואטסאפ לוחצים לחיצה ארוכה על הודעה קולית ← שיתוף ← שטף. בוחרים עדין/מלא, מאזינים, ולוחצים "שליחה לוואטסאפ".
* **בנייה:** כל push ל-`main` מריץ את הבדיקות, בונה APK ב-GitHub Actions ומפרסם אותו כ-Release. לבנייה מקומית: Android Studio, או `cd android && gradle assembleRelease`.
* **מנוע ההחלקה** (`android/app/src/main/java/app/shetef/dsp/`) הוא תרגום ל-Kotlin של גרסת ה-Python. הבדיקה `PipelineTest` מוודאת ששתיהן מוציאות את אותן תוצאות על אותם קבצים (`tests/make_android_fixtures.py` מייצר אותם).
* **מגבלה:** בלי תמלול, האפליקציה לא תופסת חזרה על מילה שלמה ("אני אני"). חזרות הברה/צליל, הארכות וחסימות כן נתפסות.
* הקובץ `shetef-test.keystore` נמצא בריפו כדי שכל גרסה תתעדכן מעל הקודמת. לפני פרסום בחנות צריך מפתח פרטי שנשמר ב-Secrets.

## גרסת שרת + ווב (Python)

אפליקציה שמקבלת הודעה קולית (הקלטה בדפדפן או קובץ מוואטסאפ), מזהה חזרות, הארכות וחסימות, מסירה אותן בחיבור חלק (cross-fade) בקול המקורי של המשתמש, ומחזירה קובץ Ogg/Opus מוכן לשליחה בוואטסאפ.

הסקירה של האפיון והפערים שמצאתי נמצאת ב-[REVIEW.md](REVIEW.md).

## מה בנוי

| רכיב | קובץ | מה עושה |
|---|---|---|
| קלט/פלט שמע | `fluency/audio_io.py` | קורא כל פורמט (opus, ogg, m4a, webm, wav, mp3) דרך ffmpeg, כותב Ogg/Opus |
| VAD | `fluency/vad.py` | Silero VAD אם מותקן, אחרת VAD אנרגטי אדפטיבי |
| תמלול (אופציונלי) | `fluency/transcribe.py` | faster-whisper עם חותמות זמן למילה ו-prompt שמעודד תמלול מילולי |
| זיהוי גמגום | `fluency/detect.py` | חזרות (אקוסטי + מתמלול), הארכות (צליל יציב ארוך), חסימות מול הפסקת מחשבה |
| עריכה | `fluency/edit.py` | חיתוך וחיבור עם cross-fade של 15ms בנקודות שקטות |
| שיבוט קול / inpainting | `fluency/inpaint.py`, `fluency/enroll.py` | ממשק להכנסת מודל עריכת דיבור + בחירת 12 השניות השוטפות ביותר מהקלטת ההרשמה |
| שרת | `fluency/server.py` | FastAPI, עיבוד בזיכרון בלבד, בלי שמירה לדיסק |
| אפליקציה | `web/` | אפליקציית ווב מותקנת (PWA) בעברית: הקלטה, בחירת עדין/מלא, השמעה, שיתוף לוואטסאפ |

### איך מבחינים בין חסימה להפסקת מחשבה

שקט באמצע דיבור נחשב **חסימה** (ומקוצר חזק) רק אם יש לו לפחות סימן אחד: רעש נשימה/מאמץ בתוך השקט, צליל קטוע קצר לפניו, צמידות לאירוע גמגום אחר, או שהוא נופל בתוך מילה לפי התמלול. אחרת הוא **הפסקה טבעית** ונשאר כמו שהוא, אלא אם הוא ארוך מאוד (מעל 1.6 שניות במצב עדין, 1.0 במלא).

### עדין מול מלא

| | עדין | מלא |
|---|---|---|
| חזרות | משאיר חזרה אחת ("ב-בית") | מסיר את כולן |
| הארכה | מעל 0.45 שנ', מקצר ל-0.2 | מעל 0.3 שנ', מקצר ל-0.12 |
| חסימה | משאיר 0.25 שנ' שקט | משאיר 0.12 שנ' |

כל הספים נמצאים ב-`DetectConfig` / `MODES` ב-`fluency/detect.py`, וצריך לכייל אותם על הקלטות אמיתיות.

## התקנה

דרוש Python 3.10 ומעלה ו-ffmpeg.

```bash
# macOS:  brew install ffmpeg      Ubuntu:  sudo apt install ffmpeg      Windows:  winget install ffmpeg
cd fluency-app
python -m venv .venv && source .venv/bin/activate      # ב-Windows: .venv\Scripts\activate
pip install -r requirements.txt                        # בסיס, בלי מודלים כבדים
pip install -r requirements-full.txt                   # מומלץ: Whisper + Silero VAD (הורדה של כמה מאות MB)
```

## הרצה

**שורת פקודה** (על הודעה שהורדת מוואטסאפ):

```bash
python -m fluency message.opus clean.ogg --mode gentle --report report.json
python -m fluency message.opus clean.ogg --mode full --whisper small          # עם תמלול
python -m fluency message.opus clean.ogg --whisper ivrit-ai/whisper-large-v3-turbo-ct2   # מודל עברי של ivrit.ai (לוודא את השם העדכני ב-Hugging Face; GPU מומלץ)
python -m fluency onboarding.m4a voice_ref.wav --enroll                        # הפקת דגימת קול מההרשמה
```

**האפליקציה:**

```bash
FLUENCY_WHISPER_MODEL=small uvicorn fluency.server:app --host 0.0.0.0 --port 8000
```

פותחים `http://localhost:8000` במחשב. בטלפון הדפדפן מאפשר מיקרופון רק ב-HTTPS, אז הדרך המהירה היא מנהרה:

```bash
cloudflared tunnel --url http://localhost:8000     # או: ngrok http 8000
```

פותחים את כתובת ה-https שמתקבלת בטלפון, ו"הוספה למסך הבית" הופכת את זה לאפליקציה. אחרי הקלטה לוחצים "שליחה לוואטסאפ", ובוחרים איש קשר בתפריט השיתוף.

## בדיקות

```bash
pip install -r requirements-dev.txt
pytest -q
```

15 בדיקות על שמע סינתטי עם אירועים ידועים: דיבור שוטף לא נפגע, הפסקה טבעית נשמרת, הפסקה ארוכה מקוצרת, הארכת עיצור ותנועה, חסימה עם רעש מאמץ, חזרת הברה (עדין משאיר אחת), חזרת מילה/תחילית/צירוף מתוך תמלול, חיבור בלי קליקים, ו-API מקצה לקצה עם Ogg/Opus. בנוסף נבדקה האפליקציה בדפדפן (Chromium) עם מיקרופון מדומה: הקלטה, עיבוד ותצוגת תוצאה.

## מגבלות ידועות (חשוב לקרוא)

* **לא נבדק עדיין על דיבור אמיתי.** הסביבה שבה נבנה לא אפשרה להוריד מודלים או הקלטות. הצעד הראשון הוא להריץ על 10–20 הודעות אמיתיות (עם הסכמה), להאזין, ולכייל את הספים. בעיקר `steady_db` (רגישות להארכות) ו-`fragment_sim_db` (רגישות לחזרות הברה).
* חזרה של מילה שלמה נתפסת רק כשיש תמלול (Whisper). בלי תמלול נתפסות רק חזרות קצרות (הברה/צליל).
* מילה שנקטעה בחסימה לא "מושלמת" עדיין. זה התפקיד של ה-Inpainter.

## הצעדים הבאים

1. איסוף 20–50 הקלטות עבריות אמיתיות עם תיוג של קלינאית (גבולות זמן לכל אירוע), ומדידת %SS, שיעור חיתוך שגוי ו-WER.
2. מודל סיווג פריימים (wav2vec2 קטן / CNN) במקום הכללים, מאומן על SEP-28k + ההקלטות העבריות + גמגום סינתטי על ivrit.ai.
3. חיבור מודל עריכת דיבור ל-`inpaint.py` (להוסיף מחלקה עם `@register("name")`) לשחזור מילים קטועות בקול המשתמש.
4. עטיפה כאפליקציה נייטיב (React Native / Flutter) עם Share Target מוואטסאפ, ועיבוד על המכשיר דרך ONNX.
